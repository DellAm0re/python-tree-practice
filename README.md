# Практична робота — Дерева (Tree)

Дев’ять задач на Python з бінарними деревами. Допоміжний `tree_utils.py` містить клас `TreeNode` та перетворення дерева між вузлами й поданням масивом (level-order).

## Завдання

1. `01_same_tree.py` — перевірка структурної та значеннєвої однаковості дерев.
2. `02_symmetric_tree.py` — дзеркальна симетрія.
3. `03_invert_binary_tree.py` — інвертування (обмін лівих і правих дітей).
4. `04_kth_smallest_bst.py` — k-те найменше значення BST через inorder.
5. `05_serialize_deserialize.py` — `Codec.serialize` і `Codec.deserialize`.
6. `06_max_path_sum.py` — максимальна сума шляху.
7. `07_binary_tree_cameras.py` — мінімальна кількість камер.
8. `08_vertical_traversal.py` — вертикальний обхід із сортуванням за рядком та значенням.
9. `09_recover_preorder.py` — відновлення дерева з preorder-запису із глибиною.

## Формат дерева

Приклади із завдання задаються списками на кшталт `[1, 2, 3, None, 4]`: це обхід у ширину, `None` означає відсутність вузла. Функція `build_tree` будує справжні вузли, а `tree_to_list` перетворює дерево назад на список. Для пустого дерева використовується `[]`.

## Складність

| № | Час | Додаткова пам'ять |
|---|---|---|
| 1 | O(n) | O(n) |
| 2 | O(n) | O(n) |
| 3 | O(n) | O(n) |
| 4 | O(h + k) | O(h) |
| 5 | O(n) | O(n) |
| 6 | O(n) | O(n) |
| 7 | O(n) | O(n) |
| 8 | O(n log n) | O(n) |
| 9 | O(n) | O(h) |

`n` — кількість вузлів, `h` — висота дерева (для задачі 9 `n` також характеризує довжину вхідного запису).
